How the server sends your run to Monad testnet.

The usual way
1Send 2Save

Crash in between, and the server wakes up thinking it never sent anything. So it sends it again.

What StrideMon does
1Sign 2Save 3Send

Crash anywhere, and it resends the exact transaction it saved. The chain only accepts it once.
